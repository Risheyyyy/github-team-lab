About Our github team

We created this website to practice real GitHub collaboration in a small development team.

Why We Built It

Learning collaboration through practice

Instead of editing the same files directly on the main branch, each student works independently using branches.

This gives us practical experience with the same workflow used by software development teams: clone, branch, commit, push, review, merge, and sync.

Skills Practiced

  • Cloning a repository
  • Creating and switching branches
  • Writing meaningful commits
  • Pushing branches to GitHub
  • Creating Pull Requests
  • Reviewing teammates' code
  • Resolving merge conflicts
  • Publishing with GitHub Pages

Our Workflow

How the team works

1. Work Separately

Each student creates a branch for their assigned page.

2. Review Together

Pull Requests are checked and discussed before merging.

3. Publish Together

The final main branch is deployed using GitHub Pages.
