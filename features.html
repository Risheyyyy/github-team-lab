What We Practiced

Core GitHub collaboration features

🌿

Branches

Contributors work safely without changing the main branch directly.

💾

Commits

Changes are saved as clear checkpoints with meaningful messages.

🔀

Pull Requests

Team members propose their work before it becomes part of main.

👀

Code Reviews

Teammates inspect changes, comment, suggest fixes, and approve work.

🧩

Conflict Resolution

Conflicting changes can be identified and manually resolved.

🚀

GitHub Pages

The final website can be hosted directly from the GitHub repository.
