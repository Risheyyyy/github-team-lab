GitHub Team Collaboration Lab

Build Together. Learn Git Together.

This multi-page website was created as a team project to practice branches, commits, pushes, Pull Requests, reviews, merging, syncing, conflict resolution, and GitHub Pages.

Learn About Us View Features

Project Goal

One website, multiple contributors

Each teammate works on a separate page using their own Git branch before submitting a Pull Request for review.

01

Create a Branch

Every contributor creates a separate branch before making changes.

02

Commit & Push

Changes are committed with clear messages and pushed to GitHub.

03

Pull Request

Team members review the work, leave comments, and approve changes.

04

Merge & Deploy

Approved changes are merged into main and published with GitHub Pages.

Team Responsibilities
